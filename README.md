# Bounty Generator ♠

Web app (PWA) per assegnare bounty casuali ai giocatori di un torneo di poker.

- Scegli il numero di giocatori (5–12) e il montepremi delle bounty.
- L'importo viene diviso in **tante bounty piccole, alcune medie e 1–2 "Jackpot"** (rapporto circa 1 : 2,2 : 4,6, con un po' di casualità), arrotondate a cifre comode; il totale torna sempre esatto.
- Le bounty vengono mescolate e assegnate a caso: tocca una carta per scoprirla, oppure "Rivela tutte".
- Nomi giocatori opzionali, salvati sul dispositivo. Funziona anche offline.

## Pubblicazione (GitHub Pages)

Settings → Pages → *Deploy from a branch* → scegli il branch e la cartella `/ (root)`.
Apri l'URL dal telefono e usa **Aggiungi a schermata Home** (Safari: tasto Condividi; Chrome: menu ⋮).
